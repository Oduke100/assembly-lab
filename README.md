### HOW TO RUN ASSEMBLY

you write code in a (.s) extension, this needs to be changed to a (.o) extension then consequently to an extensionless file that can be run
Thus;
	step 1, as <input_file(.s extension)> -o <output_file(.o extension)>
	step 3, ld <input_file(.o extension)> -o <output_file(extensionless)>
